# 功能体检（Health Check）

一键跑：

```bash
npm start        # 先确保挂件在运行（或 npm run server 只跑本地服务）
npm run health
# 等价于： electron tools/health-check.mjs
```

> **前置**：体检会去访问 `http://127.0.0.1:38900`，所以**挂件（或 `npm run server`）必须先跑着**。
> 如果服务没起来，脚本会明确提示并提前退出（不会刷一屏 `fetch failed`）。

**两条保证**（写在 `tools/probe.mjs` 基座里）：

- **默认静音**：探针窗口创建后立刻 `setAudioMuted(true)`。静音只掐掉音频输出，Web Audio 图照跑 —— 所以"有没有起播"依然可验证，但**不会出声打扰你**。
- **隔离 profile**：使用 `%TEMP%/whale-probe/<名字>` 作为 `userData`，探针里的点击/拖拽/改设置**不会污染你的真实配置**（位置、尺寸、已读 seq）。

体检结束会打印通过率，并用退出码表示成败（`0` 通过 / `1` 有失败）。

## 覆盖项

| # | 项目 | 检查内容 |
|---|---|---|
| 1 | **接口矩阵** | 19 条 `/dsh-whale/*` 路由是否都返回 200（余额/账本/泡泡/角色/音效/图库/素材…） |
| 2 | **渲染** | 挂件是否挂载、是否贴角（离右/离下 = 0）、角色形象图是否加载成功、字号比例是否正常（`amount/base ≈ 0.1248`） |
| 3 | **交互** | 真实输入事件：点鲸鱼 → 泡泡打开；点泡泡 → 推进到下一屏；悬停 → ☰ 菜单打开（并统计入口数） |
| 4 | **拖拽** | 用 CDP 注入真实指针序列拖动，落点位移应与拖拽距离一致；位置锚点应写入 `localStorage['dshw-pos']`（`v:2` 净距离格式） |
| 5 | **音效链路** | 拦截 `last-turn.json` 模拟「一轮结束」，应观察到音频起播次数 +1，且请求的是配置里的任务结束音；同时应弹出金额泡泡 |

> 测「点鲸鱼」必须按**角色图自己的 `rect`** 定位（`img.dshwv-img`），因为挂件的命中判定读的是**图像 alpha**，图只占挂件盒子的一部分。这是排查时踩过的坑，已固化进 `tools/probe.mjs`。

## 已知行为（不是 bug）

| 现象 | 说明 |
|---|---|
| **点鲸鱼不会切换台词** | 默认 `tapAdvance:false`：**点鲸鱼 = 打开/重置，点泡泡 = 推进下一屏**。想改就去「按压泡泡设置」打开开关 |
| **消耗/预警泡泡在场时点鲸鱼没反应** | 设计如此 —— 这类泡泡优先级最高，需**点泡泡**关闭 |
| **长句在泡泡里折行** | 内置的那批长句用的是模块字号（约 21px），本来就设计成两行。我们只把「好模型…↓ / 好女孩…↓ / 哦鲸鲸…」等 4 处默认字号降到了 `size:15` 以避免折行 |
| **金额泡泡 5 秒后自动消失** | `turnCostCloseMs` 默认 5000ms；可在「音效与提示 → 每轮消耗提示」里改 |
| **「点鲸鱼」的声音与「任务结束音」相同** | 若两者选了同一个音效就会听不出来；默认已把任务结束音设为内置「预设 A」、按压音效设为小鸭子组，便于区分 |
| **首次打开会补播一轮** | 挂件用 `localStorage['dshw-last-seq']` 记住已读轮次；若记忆值落后（换浏览器/清缓存），会把最近一轮补播一次 |

## 环境差异导致上游功能不可用（OpenCode 环境）

| 上游能力 | 状态 | 原因 |
|---|---|---|
| DSH 账号登录态查余额 | ❌ | 没有 DSH 账号服务（`ctx.get('deepseekAccount')` 为 null） |
| 提问 / 授权提示音与提示泡泡 | ❌ | 没有 DSH 会话事件（`wait.json` 恒为 `pending:null`） |
| `{session}` 对话名 | ⚠️ 回落「当前对话」 | 宿主不提供 `sessionTitle` |
| 「每轮消耗」金额 | ⚠️ 估算 | 取 OpenCode 上报的估算 cost × `WHALE_USD_CNY`（默认 7.1），与官方账单可能不一致 |
